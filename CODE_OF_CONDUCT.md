# Code of Conduct

The sos-vault project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

Please read the full text at the canonical URL above. The short version: be respectful, assume good faith, focus on the work, and remember that a global open-source community includes people with very different backgrounds and communication styles.

## Enforcement contact

Reports of unacceptable behaviour can be sent privately to `conduct@sos-vault.com`. Reports will be reviewed by the project maintainers and handled per the enforcement guidelines in the Contributor Covenant.

For security vulnerabilities (a different category from conduct concerns), use the dedicated channel in [`SECURITY.md`](SECURITY.md).

## Scope

The code of conduct applies to all project spaces: GitHub issues and pull requests, the discussion forum, any community Slack/Discord we run, in-person meetups, and any public channel where someone is representing the project.
